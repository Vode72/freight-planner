STATUS-KETJU: Suunniteltu → Vahvistettu → Käynnissä → Toimitettu → Laskutettu
- Laskutettu = lukittu, ei muutoksia
- Vahvistus → automaattinen trailervuokra (400 osto + 401 myynti)
- Toimitettu → delivered_at timestamp asetetaan automaattisesti (OTD-laskenta)

- Hanko - Lübeck (Transfennica) 1010€

210(KOTIMAAN AJO), 220(MANTEREEN AJO), 300(SAKSAN TIEMAKSU),
310(HOLLANTI+SAKSA), 400(TRAILERVUOKRA osto), 401(myynti),
410(TANKKAUS), 500(LAUTTA), 510(SATAMA), 600(ADR), 610(LÄMPÖTILA),
700(KÄSITTELY), 799(MUUT), 800(ODOTUS), 810(LISÄKÄSITTELY),
820(MUU), 830(YLIKÄYTTÖ osto), 831(myynti)

- Standard: Pressutrailer, Megatrailer
- Max LDM: 13,6m | Max paino: 24 000kg

REITTIMATCH-LOGIIKKA: good ✅ / warning ⚠️ / bad ❌
- Sama maa + sama postialue → good
- Sama maa eri alue → warning
- Naapurimaa → warning
- Muu → bad

TÄYTTÖASTEEN LASKENTA:
- LDM%:   käytetty / 13,6m
- Paino%: käytetty / 24 000kg
- Rajoittava tekijä ratkaisee (suurempi % = todellinen täyttöaste)

MITÄ RAKENNETAAN (päätökset lyöty lukkoon):

1. LAUTTAKULU PER ORDER
   - Lauttakulu (koodi 500) jaetaan tasan kaikille tripin ordereille
   - Näkyy TripDetailin Kustannukset-välilehdellä per order erittelynä
   - Laskenta: ferry_cost / COUNT(orders WHERE trip_id = X)

2. POLTTOAINELISÄ-AUTOMAATIO
   - Kuukausittainen kerroin (fuel_rates-taulu)
   - Kun rahti (koodi 120) syötetään → polttoainelisä (koodi 200) lasketaan automaattisesti
   - Näkyy erillisenä rivinä laskulla
   - Kerroin hallitaan Hallinta-osiossa (⛽ Polttoainekerroin)
   - Dispatcheri voi muokata tarvittaessa

3. FEC-KUITTAUSSIVU (Freight Plannerin oma toiminto)
   - Kuljettaja saa linkin: /driver/TRP-2026-001
   - Kuittaa: Lastaus alkanut / Lastaus valmis / Purku alkanut / Purku valmis
   - Timestampit tallentuvat trips-tauluun
   - Kolme automaattia tästä:
     a) Odotusaika: aikaikkunan ylitys → koodi 800 automaattisesti costs-tauluun
     b) OTD: delivery_completed_at vs. delivery_date
     c) Seisontapäivät: delivery_completed_at → seuraava loading_started_at

4. SEISONTAPÄIVÄT
   - Lasketaan FEC-timestampeista automaattisesti
   - Näkyy TrailerList-näkymässä prioriteettijärjestyksessä
   - Vanhin seisoja = korkein prioriteetti seuraavaan keikkaan
   - Hälytys jos trailer seisonut yli X päivää

5. OTD (On-Time Delivery)
   - Seurataan "Toimitettu"-statuksen aikaleimaa
   - Ajoissa = toimitettu delivery_date:na tai ennen
   - Myöhässä 1pv = pieni poikkeama
   - Myöhässä 2+pv = reklamaatioriski
   - KPI-kortti Dashboardiin

6. TÄYTTÖASTE
   - LDM-pohjainen + painopohjainen (molemmat)
   - Rajoittava tekijä ratkaisee

    📦 Ordereja per keikka                  ← AVG(orders per trip)
  Trendiviiva: täyttöaste per viikko
  Pylväät: täyttöaste per kohdeMaa
  Taulukko: Carrier | Keikkoja | Avg LDM% | Avg Paino% | Avg Ordereja

SIVU 2 — "Kannattavuus"
  KPI-kortit:
    💵 Kokonaismyynti                       ← SUM(costs WHERE type=revenue)
    💸 Kokonaisostot                        ← SUM(costs WHERE type=cost)
    📈 Kate €                               ← myynti - ostot
    📊 Kate %                               ← kate / myynti
  Trendiviiva: kate per kuukausi
  Pylväät: kate per carrier
  Pylväät: kate per kohdeMaa (FI→DE, FI→NL jne.)
  Taulukko: Trip | Reitti | Ostot | Myynti | Kate€ | Kate% | Status

SIVU 3 — "Toimitustäsmällisyys"
  KPI-kortit:
    ✅ OTD% — ajoissa                       ← delivered_at <= delivery_date
    ⚠️  Myöhässä 1 pv                        ← poikkeama 1pv
    ❌ Myöhässä 2+ pv                       ← reklamaatioriski
    ⛴️  Lauttamyöhästymiset                  ← ferry_route + OTD
  Trendiviiva: OTD% per viikko
  Pylväät: OTD% per carrier
  Pylväät: OTD% per kohdeMaa

SIVU 4 — "Kalusto"
  KPI-kortit:
    📅 Avg. seisontapäivät                  ← delivery_completed_at → loading_started_at
    🔴 Pisimpään seisonut trailer            ← MAX(seisonta-aika)
    🔄 Kiertonopeus (keikkaa/kk per trailer) ← COUNT(trips) / trailer / kk
    💰 Seisontakustannus                    ← seisontapäivät × leasing_rate
  Taulukko: Trailer | Tyyppi | Seisontapäivät | Keikkoja/kk | Käyttöaste% | Kustannus

6.  CMR + Transport Order + Gateway Instruction List + PDF-lasku

    KOLME DOKUMENTTIA — milloin mikäkin:
    ┌─────────────────────────┬──────────────────────┬─────────────────────┐
    │ Dokumentti              │ Milloin              │ Kenelle             │
    ├─────────────────────────┼──────────────────────┼─────────────────────┤
    │ Transport Order         │ Trip vahvistetaan    │ Kuljetusyhtiö       │
    │ Gateway Instruction List│ Terminaalilastaus    │ Terminaali/gateway  │
    │ CMR                     │ Lastauksen yhteydessä│ Kuljettaja + vast.  │
    └─────────────────────────┴──────────────────────┴─────────────────────┘

    KAKSI CARRIER-TYYPPIÄ PER TRIP:
      Mantereen vetäjä: lastaa FI → ajaa satamaan → lautta → kohdeMaa
      Kotimaan vetäjä:  hakee satamasta → purkaa Suomessa
      Trips-tauluun lisättävä:
        carrier_id            (kotimaan, jo olemassa)
        truck_plate           (kotimaan, jo olemassa)
        continent_carrier_id  (mantereen vetäjä) ── TULOSSA
        continent_truck_plate (mantereen rekka)  ── TULOSSA

    SEND INSTRUCTIONS -WORKFLOW (PEV:n mallin mukaan):
      Trip vahvistetaan →
        1. Transport Order PDF → sähköpostilla kuljetusyhtiölle
        2. SMS kuljettajalle (automaattinen teksti + FEC-linkki)
        3. Kuljettaja kuittaa FEC-linkistä

    TULOSTUS/LÄHETYSVALIKKO TripDetailissa:
      📤 Lähetä ohjeet
        ├── 📧 Transport Order (PDF sähköpostilla kuljetusyhtiölle)
        │     Mantereen vetäjä: lastausohjeet FI → satama
        │     Kotimaan vetäjä:  purkuohjeet satama → kohteet
        │     Valitaan kumpi lähetetään — tai molemmat erikseen
        ├── 💬 SMS kuljettajalle (automaattinen teksti)
        │     Muoto:
        │       Unit: [truck] [trailer]
        │       Delivery 1: [osoite] - [ldm]/[kg]/[qty][pallet_type] - [lastauskaupunki]
        │       Delivery 2: ...
        │       Kuittaa toimitukset: https://freightplanner.com/driver/TRP-2026-001
        ├── 🏭 Gateway Instruction List → PDF terminaalille
        └── 📋 CMR                     → PDF kuljettajalle

    TRANSPORT ORDER — sisältö:
    Kentät valmiina Freight Plannerissa lähes kokonaan:
      - carriers (nimi, osoite, VAT lisättävä ❌)
      - trips (trip_id, ferry_route, adr, temperature_controlled, truck_plate, trailer_id)
      - orders (reitti, loading_point, quantity, ldm, weight, goods_description,
                loading_instructions, order_reference)
      - FEC-linkki samassa näkymässä: /driver/TRP-2026-001
        → Transport Order näkymä (tulostettava PDF)
        → FEC-kuittauspainikkeet (Lastaus alkanut/valmis, Purku alkanut/valmis)
    Lisättävä tietokantaan:
      carriers: + vat_number
      settings: + forwarder_name, forwarder_address, forwarder_contact (kiinteä)

    GATEWAY INSTRUCTION LIST — terminaalilastauksen ohje
    Kentät valmiina lähes kokonaan:
      - trips (trip_id, trailer_id, truck_plate, ferry_departure/arrival)
      - carriers (road supplier)
      - orders per rivi (CD LOAD):
          consignor → consignee, inbound ref, quantity, ldm, cbm, weight,
          goods_description, loading_instructions (remarks), adr
      - SUM OUTBOUND: lasketaan automaattisesti
    Lisättävä:
      - Viivakoodi per order (generoitaisiin automaattisesti)
      - "Scanned for ARR/INV" status → FEC-kuittaus päivittää reaaliajassa
      - Gateway-terminaali (kiinteä tai trips-tauluun)
    FEC-yhteys:
      Kuljettaja kuittaa orderit terminaalissa
      → "Scanned for ARR/INV: YES" päivittyy automaattisesti
      → Timestamp tallentuu

    CMR — kansainvälinen rahtikirja
    Kentät valmiina lähes kokonaan:
      - consignor, consignee, loading/unloading point, quantity, weight,
        goods_description, loading_instructions, incoterms, truck_plate, trailer_id
    CMR-numero generoidaan automaattisesti
