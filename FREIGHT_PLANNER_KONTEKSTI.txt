Päivitetty: 09.05.2026
============================================================

ROOLI:
Senior Full Stack Developer — React + Python Flask + SQLite

PROJEKTIN KUVAUS:
Freight Planner on TMS-tyylinen kuljetustenhallintatyökalu.
Kaikki data on keksittyä demodataa — ei oikeita asiakasnimiä, rekkareita tai työdataa.

TEKNINEN STACK:
- Frontend: React 18, JavaScript, inline CSS
- Teema: tumma #0f172a, oranssi aksentti #f97316
- Backend: Python Flask, SQLite (freight.db)
- REST API: http://127.0.0.1:5000
- Frontend: http://localhost:3000
- GitHub: github.com/Vode72/freight-planner
- Demo: demo / freight2024

VALMIIT API-ENDPOINTIT
============================================================

Auth:       POST /api/login
Reference:  GET /api/trailer-types, /api/trailer-specs, /api/incoterms
            GET /api/transport-types, /api/statuses, /api/ferry-routes
            GET /api/cost-codes, /api/pallet-types, /api/next-order-reference
Trailers:   GET /api/trailers
            ✅ POST /api/trailers
            ✅ PUT /api/trailers/:id (kaikki kentät)
            ✅ DELETE /api/trailers/:id (tarkistaa aktiiviset keikkalinkit)
Carriers:   GET /api/carriers
            ✅ POST /api/carriers
            ✅ PUT /api/carriers/:id
            ✅ DELETE /api/carriers/:id (tarkistaa aktiiviset keikkalinkit)
Trucks:     GET /api/trucks?carrier_id=
            ✅ POST /api/trucks
            ✅ PUT /api/trucks/:id
            ✅ DELETE /api/trucks/:id (tarkistaa aktiiviset keikkalinkit)
Trips:      GET/POST /api/trips, GET/PUT/DELETE /api/trips/:id
            ✅ GET palauttaa total_weight, total_loading_meters, total_volume
            PUT /api/trips/:id/status, POST /api/trips/:id/confirm-invoice
Orders:     GET/POST /api/orders, GET/PUT/DELETE /api/orders/:id
            POST/DELETE /api/trips/:id/orders/:id
Costs:      GET/POST /api/trips/:id/costs, PUT/DELETE /api/costs/:id
Route:      GET /api/route-match
Customers:  GET/POST /api/customers, GET/PUT/DELETE /api/customers/:id

BISNESLOGIIKKA
============================================================

STATUS-KETJU: Suunniteltu → Vahvistettu → Käynnissä → Toimitettu → Laskutettu
- Laskutettu = lukittu, ei muutoksia
- Vahvistus → automaattinen trailervuokra (400 osto + 401 myynti)

LAUTTAREITIT:
- Helsinki - Travemünde (Finnlines) 1050€
- Hanko - Lübeck (Transfennica) 1010€
- Hanko - Rostock (Finnlines) 750€
- Kotka - Antwerpen (Transfennica) 1800€

KULUKOODIT: 100(SPOT), 120(FREIGHT), 200(POLTTOAINELISÄ),
210(KOTIMAAN AJO), 220(MANTEREEN AJO), 300(SAKSAN TIEMAKSU),
310(HOLLANTI+SAKSA), 400(TRAILERVUOKRA osto), 401(myynti),
410(TANKKAUS), 500(LAUTTA), 510(SATAMA), 600(ADR), 610(LÄMPÖTILA),
700(KÄSITTELY), 799(MUUT), 800(ODOTUS), 810(LISÄKÄSITTELY),
820(MUU), 830(YLIKÄYTTÖ osto), 831(myynti)

KAPASITEETTITYYPIT:
- Thermo: Umpikaappi, Sivuaukeava, Umpikaappi 2-koneinen
- Standard: Pressutrailer, Megatrailer

REITTIMATCH-LOGIIKKA: good ✅ / warning ⚠️ / bad ❌
- Sama maa + sama postialue → good
- Sama maa eri alue → warning
- Naapurimaa → warning
- Muu → bad
